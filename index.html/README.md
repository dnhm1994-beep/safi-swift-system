# 🏦 نظام إدارة وتتبع السويفتات المالية - شركة صافي

تطبيق ويب متكامل وحديث لإدارة وتتبع حركة الحوالات والسويفتات المالية (Swift Wire Transfers) لشركة **صافي للحوالات المالية**. تم تصميم التطبيق ليعمل بكفاءة عالية على مختلف الأجهزة مع دعم وضع العرض الداكن (Dark Mode) والطباعة المباشرة.

---

## 🌟 المميزات الرئيسية

* **لوحة إحصائيات تفاعلية:** عرض فوري لإجمالي السويفتات، والحالات المختلفة (قيد التنفيذ، معلق، تم الوصول).
* **إدارة الحوالات والسويفتات:** إضافة، تعديل، مسح، وتغيير سريع لحالة السويفت بنقرة واحدة.
* **إدارة المستخدمين والصلاحيات (Admin & Users):**
  * دعم حساب مدير النظام (Admin) بجميع الصلاحيات.
  * إمكانية إنشاء يوزرات فرعية وتحديد صلاحيات خاصة بكل يوزر (إضافة، تعديل، حذف، تصدير).
* **تصدير واستيراد Excel:** دعم كامل لتحميل سجل البيانات وتحديثه عبر ملفات Excel (`.xlsx`, `.xls`).
* **تصفية وبحث سريع:** إمكانية البحث باسم المرسل، المنفذ، أو الملاحظات، والفلترة حسب حالة السويفت.
* **ساعة حية وحفظ آلي:** يعتمد على التخزين المحلي للمتصفح (`LocalStorage`) للحفاظ على البيانات دون الحاجة لسيرفر خارجي.
* **جاهز للطباعة:** تنسيق مخصص للطباعة وتوليد تقارير سريعة مع التواريخ.

## 🛠️ التقنيات المستخدمة

* **HTML5 / JavaScript (ES6+):** هيكلة وبرمجة التطبيق بالكامل.

## 🚀 طريقة التشغيل والنشر

### التشغيل المحلي:
1. قم بتحميل الملف `index.html`.
2. افتح الملف باستخدام أي متصفح حديث (Chrome, Firefox, Edge).

### النشر عبر GitHub Pages:
1. ارفع ملف `index.html` وهذا الملف `README.md` إلى مستودع GitHub الخاص بك.
2. انتقل إلى **Settings** > **Pages**.
3. اختر الفرع `main` وانقر على **Save**.
4. سيعطيك غيت هاب رابطاً أونلاين لتشغيل التطبيق فوراً.
